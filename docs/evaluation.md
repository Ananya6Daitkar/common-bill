# Evaluation protocol

## Engineering evidence versus impact

Successful API calls, tests and builds establish integration correctness. They do not establish customer value, audience interest, attendance, revenue, or judge scores.

## Blind comparison

Both arms receive the same brief, catalog metadata, exclusions, feedback, model ID, and two-call LLM planning opportunity. The Qloo arm additionally receives cultural results. Input fingerprints must match. There is no hidden deliberately weak baseline.

The Qloo arm may have fewer final candidates because unsupported or missing evidence cannot be invented. Its model-directed evaluation scope is bounded and disclosed. This is an end-to-end workflow comparison, not a controlled estimate of a single model parameter's causal effect.

Randomize A/B display order. Ask actual operators which proposal is more useful and why. Record no preference when appropriate. Do not score success using Qloo affinity alone. Do not manufacture participant identities or aggregate statistics.

## Pilot worksheet

For each consenting cinema programmer / bookseller:

- Role and consent (keep contact details outside the public repository).
- Is this a real operational task? What do they currently do?
- Are the catalogs and costs verified?
- Which proposal would they consider running, if either?
- What remaining preparation would be necessary?
- Did either proposal violate a practical requirement?
- Time spent completing the task using each workflow; note ordering effects.
- Permission to quote their feedback in the submission.

A small convenience sample supports an early pilot claim only. Attendance and revenue require an actual event and an appropriate comparison.

## 60-second demo

1. Show actual catalogs and the brief; identify any illustrative inputs.
2. Resolve exact entities and run the Qloo-backed proposal.
3. Inspect directional evidence and practical checks.
4. Make the bookseller unavailable; show permitted repair or an honest infeasibility result.
5. Show preserved elements and changed cost/host.
6. Export the draft event brief and decision receipt.

Never present rehearsal selection as a Qloo recommendation. Never claim an LLM comparison ran before both arms have been verified.
